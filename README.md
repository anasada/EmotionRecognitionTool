# Emotion Recognition Tool

Human-Centered AI case study designing an accessible multimodal emotion recognition tool for individuals with ASD.

## Overview

This repository contains a Human-Centered AI case study completed as part of a graduate Human-Centered AI course. Over the course of the project, I designed a mobile application that helps individuals with Autism Spectrum Disorder (ASD) recognize emotions through AI-assisted learning and multimodal emotion classification.

Rather than focusing solely on emotion prediction, the project applies Human-Centered AI principles to design a system that supports long-term learning, accessibility, and responsible AI deployment.

## Problem

Individuals with Autism Spectrum Disorder (ASD) may experience challenges recognizing emotional cues, making some social interactions more difficult. Existing AI emotion recognition tools often focus solely on classifying facial expressions, providing predictions without helping users build lasting understanding.

The proposed mobile application consists of two primary components.

### Learn

The Learn section provides an AI-curated learning experience that helps users build long-term emotion recognition skills through:

- Personalized lesson plans
- Guided explanations of emotional cues
- Practical communication strategies
- Practice exercises and review topics

### Classify

The Classify section allows users to receive emotion classifications through multiple input modalities.

Users can choose between:

- **Text:** Describe a social situation, ask questions, or provide excerpts to an LLM for contextual emotion recognition.
- **Image:** Upload an image for AI-based facial emotion recognition after confirming that appropriate consent has been obtained.

Supporting both text and image input makes the system more flexible while addressing privacy, accessibility, and real-world usage scenarios.

## AI System Design

The project includes a conceptual design for the underlying AI system, considering not only the user interface but also the machine learning pipeline.

The proposed system would:

- Personalize lesson plans based on user progress and completed lessons
- Support multimodal emotion classification using both text and image inputs
- Learn from user feedback to improve recommendations over time
- Collect appropriate behavioral metrics while accounting for fairness, privacy, and transparency

The case study also outlines the data requirements, training considerations, evaluation metrics, and user-facing explanations necessary to support responsible deployment.

## Evaluation Framework

The project defines measurable success metrics to guide future iterations of the system, including:

- Monitoring the balance between text and image classifier usage
- Measuring lesson completion rates to evaluate personalized learning
- Tracking user feedback on AI recommendations
- Measuring long-term engagement through weekly return rates

These metrics were designed to inform future user studies and iterative improvements to the system.

## Responsible AI Considerations

Responsible AI considerations were incorporated throughout the design process, including:

- Privacy and informed consent
- Human safety
- Accessibility
- Fairness and bias evaluation
- Legal and societal impacts
- Sustainability
- Governance considerations
